# YYG · אתר עיצוב ובניית אתרים

אתר תדמית בעמוד אחד, בנוי לפי חמשת הכללים מהסרטון [I Studied 10,000 AI Websites](https://www.youtube.com/watch?v=mImbbszCjCI). הוא כתוב ב־HTML, CSS ו־JS נקיים, בלי ספריות ובלי שלב בנייה. הגופנים, הלוגו והתמונות שמורים בתוך המאגר.

יצירת קשר בטלפון (שיחות בלבד) ובמייל. אין באתר וואטסאפ או SMS.

## איך מיושמים חמשת הכללים

### 1. מבחן המראה
המסך הראשון עונה על שלוש השאלות:
- **למי:** "לעסקים קטנים ולמוסדות".
- **מה מקבלים:** תוצאה, לא רשימת יכולות: "אתר שנטען מהר ומביא פניות", ולפני שבונים רואים כמה עיצובים ובוחרים.
- **מה עושים עכשיו:** כפתור אחד, "לתכנן את האתר שלי". מתחתיו שורה שקטה עם הטלפון למי שמעדיף לדבר.

הכותרת משתמשת במילים שאנשים מחפשים: "בניית אתר לעסק".

### 2. כלל המרקר (60-30-10)
הצבעים לקוחים מהלוגו:
- **60%:** פלדה כהה ברקע.
- **30%:** פלדה בהירה לטקסט, למסגרות ולכרטיסים.
- **10%:** זהב, **רק** על שלושה כפתורי פעולה: "לתכנן את האתר שלי", "לשלוח את התכנית במייל" ו"לשלוח מייל".

כל שאר הכפתורים והקישורים בצבע הטקסט. הטורקיז מופיע רק בתוך הלוגו.

### 3. רקע, אמצע, חזית
- **רקע:** הילה פלדה רכה וטבעת חוגה בהשראת הלוגו.
- **אמצע:** מסגרת העיצובים בפתיחה "שוברת את הקצה" ויורדת לתוך החלק של העבודות. בעבודות, הטלפון יוצא מהמסגרת.
- **חזית:** הכפתור הזהוב וכרטיס התוצאה במתכנן מורמים עם צל.

### 4. תנועה עם תפקיד
- **בפתיחה:** אין שום תנועה שרצה לבד, והטקסט זמין מיד. התמונה מתחלפת רק בלחיצה.
- **הכיף שבאפיה:** מרוץ מהירות שמראה את התוצאה. הפס של האתר החדש מגיע לסוף אחרי 0.8 שניות, והפס של האתר הקודם ממשיך עד 3.4 שניות. המספרים כתובים מההתחלה, ויש כפתור "להריץ שוב".
- **איך עובדים:** הקו מתמלא בזמן הגלילה ומוביל את העין לשלב הבא.
- **במתכנן:** מה שהשתנה מהבהב פעם אחת.
- **דבר אחד זז בכל מסך.**
- **מתג "תנועה":** בראש העמוד, נשמר בדפדפן. אם במערכת ההפעלה מוגדר "הפחתת תנועה", האתר נפתח כשהתנועה כבויה.

### 5. דוגמה חינם
המתכנן הוא שאלון קצר עם הערכת מחיר:
- **השאלות:** מה יש לכם, מה הלקוח צריך לעשות באתר, ומי יעדכן.
- **התוצאה:** מסלול (דף נחיתה, אתר עם אזור ניהול, אתר ומועדון עדכונים), רשימת עמודים, יכולות והערכת מחיר.
- **השליחה:** התכנית נשלחת במייל עם כל הפרטים, או מועתקת בלחיצה.

## לפני שמעלים לאוויר

- [ ] **מייל וטלפון:** `CONFIG.email` ו־`CONFIG.phone` בראש `assets/site.js`. הסקריפט מעדכן לבד את כל הקישורים בעמוד. כדאי לעדכן גם את הטקסט הקבוע ב־`index.html` (למי שהדפדפן שלו לא מריץ JS) וב־`accessibility.html`.
- [ ] **מחירים:** `CONFIG.prices` ו־`CONFIG.english`. כרגע הם לקוחים מהצעת המחיר של פרחי שמיים: 1,500, 3,000 ו־4,300 ₪, ולגרסה באנגלית עוד 200, 400 ו־500 ₪. `prices: null` מסתיר את ההערכה.
- [ ] **אינדוקס בגוגל:** להסיר את `<meta name="robots" content="noindex">` מ־`index.html`.
- [ ] **מפת אתר:** להוסיף `sitemap.xml` ושורת `Sitemap:` ב־`robots.txt` עם הדומיין הקבוע.

## מבנה

```
index.html            העמוד
accessibility.html    הצהרת נגישות
assets/site.css       העיצוב (צבעים וגדלים בראש הקובץ)
assets/site.js        פרטי קשר, מחירים, מתג תנועה, מרוץ המהירות, הקו בתהליך והמתכנן
assets/fonts/         IBM Plex Sans Hebrew ו־Gveret Levin (רישיון OFL)
assets/img/           לוגו, אייקונים וצילומי מסך בפורמט WebP
```

## עבודה חדשה

1. לצלם את האתר במחשב (1440×900) ובטלפון (390 רוחב).
2. לשמור ב־`assets/img/` בשמות `שם-1200.webp`, `שם-720.webp` ו־`שם-m.webp`.
3. להעתיק בלוק `<article class="case">` ב־`index.html` ולעדכן טקסט, תמונות וקישורים.
