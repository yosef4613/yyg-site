# אתר עיצוב ובניית אתרים

אתר תדמית בעמוד אחד: HTML, CSS ו־JS נקיים, בלי ספריות ובלי שלב בנייה. הגופנים והתמונות שמורים בתוך המאגר.

## מה יש בעמוד

1. **פתיחה:** מי, מה, וכפתור וואטסאפ. לצידה מסגרת שמחליפה בין ארבעה מכיווני העיצוב של הכיף שבאפיה ובין האתר שנבנה, כדי להראות את דרך העבודה.
2. **עבודות:** הכיף שבאפיה (כולל השוואת מהירות 8.5 שניות מול כ־2 שניות) ופרחי שמיים (חמש חוויות עיצוב).
3. **איך עובדים יחד:** חמישה שלבים, עם קישורים לשאלון ולשאלון המשוב האמיתיים.
4. **מתכנן אתר:** שלוש שאלות, ומתקבלים מסלול מומלץ (דף נחיתה, אתר עם אזור ניהול, אתר ומועדון עדכונים), רשימת עמודים ויכולות. התכנית נשלחת בוואטסאפ.
5. **מה יש בכל אתר**, **שאלות** ו**יצירת קשר**.

איך מיושמים 5 הכללים:
- **מבחן המראה:** המסך הראשון אומר למי (עסקים ומוסדות), מה מקבלים (כמה עיצובים לפני שבונים, אתר מהיר עם וואטסאפ) ומה עושים (כפתור אחד).
- **60-30-10:** נייר אפור־כחלחל 60%, דיו כחול כהה 30%, ירוק רק על כפתורי וואטסאפ. ורוד משמש רק להערות בכתב יד ולסימני החיתוך.
- **רקע, אמצע, חזית:** המסגרת עם סימני חיתוך, צילום המסך בתוכה, והטלפון שיוצא ממנה.
- **תנועה עם תפקיד:** אין אנימציה שרצה לבד. התמונה מתחלפת רק בלחיצה, ופריט חדש במתכנן מהבהב פעם אחת. יש תמיכה בהפחתת תנועה.
- **דוגמה חינם:** מתכנן האתר.

## לפני שמעלים לאוויר

- [ ] שם העסק: כרגע "יוסף". מופיע ב־`index.html` (כותרת, לוגו, תחתית, נתונים מובנים), ב־`accessibility.html` ובהודעות ב־`assets/site.js`.
- [ ] מספר וואטסאפ: `CONFIG.whatsapp` בראש `assets/site.js` (כרגע `972500000000`).
- [ ] טלפון ומייל: באזור יצירת הקשר ב־`index.html` ובהצהרת הנגישות.
- [ ] להסיר את `<meta name="robots" content="noindex">` מ־`index.html`, כדי שגוגל יוכל להציג את האתר.
- [ ] להוסיף `sitemap.xml` ושורת `Sitemap:` ב־`robots.txt` עם הדומיין הקבוע.

## מבנה

```
index.html            העמוד
accessibility.html    הצהרת נגישות
assets/site.css       העיצוב (צבעים וגדלים מוגדרים בראש הקובץ)
assets/site.js        פרטי קשר, החלפת העיצובים והמתכנן
assets/fonts/         IBM Plex Sans Hebrew ו־Gveret Levin (רישיון OFL)
assets/img/           צילומי מסך בפורמט WebP
```

## עבודה חדשה

1. לצלם את האתר במחשב (1440×900) ובטלפון (390 רוחב).
2. לשמור ב־`assets/img/` בשמות `שם-1200.webp`, `שם-720.webp` ו־`שם-m.webp`.
3. להעתיק בלוק `<article class="case">` ב־`index.html` ולעדכן טקסט, תמונות וקישורים.

## העלאה

אתר סטטי: מעלים את כל התיקייה לשורש הדומיין (`public_html` בהוסטינגר), או מחברים את המאגר לפריסה אוטומטית מ־GitHub.
