# YYG · אתר עיצוב ובניית אתרים

אתר תדמית בעמוד אחד, בנוי לפי חמשת הכללים מהסרטון [I Studied 10,000 AI Websites](https://www.youtube.com/watch?v=mImbbszCjCI). הוא כתוב ב־HTML, CSS ו־JS נקיים, בלי ספריות ובלי שלב בנייה. הגופנים, הלוגו והתמונות שמורים בתוך המאגר.

יצירת קשר בטלפון (שיחות בלבד) ובמייל. אין באתר וואטסאפ או SMS.

## איך מיושמים חמשת הכללים

### 1. מבחן המראה
המסך הראשון עונה על שלוש השאלות:
- **למי:** "לעסקים קטנים ולמוסדות".
- **מה מקבלים:** "אתר שנטען מהר ומביא פניות", ולפני שבונים רואים כמה עיצובים.
- **מה עושים עכשיו:** כפתור אחד, "לתכנן את האתר שלי". מתחתיו שורה שקטה עם הטלפון.

### 2. כלל המרקר (60-30-10)
- **60%:** פלדה כהה ברקע.
- **30%:** פלדה בהירה לטקסט, למסגרות ולכרטיסים.
- **10%:** זהב מוברש כמו בלוגו, **רק** על שלושה כפתורי פעולה: "לתכנן את האתר שלי", "לשלוח את התכנית במייל" ו"לשלוח מייל".

### 3. רקע, אמצע, חזית
- **רקע:** פלדה מוברשת, הילה רכה וטבעת חוגה מהלוגו.
- **אמצע:** חפיסת העיצובים יורדת לתוך החלק של העבודות, והטלפון יוצא מהמסגרת.
- **חזית:** הכפתור הזהוב, מרוץ המהירות וכרטיס התוצאה במתכנן מורמים עם צל.

### 4. תנועה עם תפקיד
לכל תנועה יש אחד משלושת התפקידים מהסרטון, ובכל מסך זז רק דבר אחד:

| איפה | מה זז | התפקיד |
|---|---|---|
| פתיחה | חפיסה תלת־ממדית של 5 כיווני העיצוב: נפרסת פעם אחת בטעינה, מתחלפת בלחיצה ונוטה לפי העכבר | להראות את המוצר מכמה זוויות |
| עבודות | המסכים במחשב ובטלפון גוללים את האתר האמיתי בזמן שגוללים את העמוד | להראות את המוצר |
| מרוץ המהירות | 8.5 שניות מול כ־2 שניות, עם כפתור "להריץ שוב" | להראות את התוצאה |
| איך עובדים | הקו מתמלא בגלילה, וכל מספר "נדלק" כשהקו מגיע אליו | להוביל את העין |
| מתכנן | המחיר מתגלגל לערך החדש, ומה שהשתנה מהבהב | להראות מה השתנה |

- **לא מחכים למילים:** אף טקסט לא מופיע באיחור. רק התמונות זזות.
- **מתג "תנועה":** בראש העמוד, נשמר בדפדפן. אם במערכת מוגדר "הפחתת תנועה", האתר נפתח כשהתנועה כבויה.
- **ברק על כפתור הזהב:** מופיע רק כשמרחפים עליו, כתגובה לפעולה.

### 5. דוגמה חינם
המתכנן הוא שאלון קצר עם הערכת מחיר:
- **התוצאה:** מסלול (דף נחיתה, אתר עם אזור ניהול, אתר ומועדון עדכונים, חנות אונליין), רשימת עמודים ויכולות.
- **המחיר:** לפי מחירי השוק בארץ.
- **השליחה:** התכנית נשלחת במייל או מועתקת בלחיצה.

## מחירים

`CONFIG.prices` ו־`CONFIG.english` בראש `assets/site.js`. ברירת המחדל היא אפשרות ב (אמצע השוק). כל המחירים לפני מע״מ.

| מסלול | א: כניסה לשוק | ב: אמצע השוק (פעיל) | ג: פרימיום |
|---|---|---|---|
| דף נחיתה | 1,500 | 2,200 | 3,500 |
| אתר עם אזור ניהול (עד 6 עמודים) | 3,500 | 4,500 | 6,500 |
| אתר ומועדון עדכונים | 5,500 | 6,900 | 9,500 |
| חנות אונליין | 6,500 | 7,900 | 12,000 |
| תוספת אנגלית (נחיתה / אתר / מועדון / חנות) | 400 / 800 / 1,200 / 1,500 | 600 / 1,200 / 1,800 / 2,000 | 900 / 1,600 / 2,400 / 3,000 |

`prices: null` מסתיר את ההערכה.

## לפני שמעלים לאוויר

- [ ] **מייל וטלפון:** `CONFIG.email` ו־`CONFIG.phone` ב־`assets/site.js`. כדאי לעדכן גם את הטקסט הקבוע ב־`index.html` וב־`accessibility.html`.
- [ ] **אינדוקס בגוגל:** להסיר את `<meta name="robots" content="noindex">` מ־`index.html`.
- [ ] **מפת אתר:** להוסיף `sitemap.xml` ושורת `Sitemap:` ב־`robots.txt` עם הדומיין הקבוע.

## מבנה

```
index.html            העמוד
accessibility.html    הצהרת נגישות
assets/site.css       העיצוב (צבעים וגדלים בראש הקובץ)
assets/site.js        פרטי קשר, מחירים, מתג תנועה, החפיסה, המסכים הגוללים, המרוץ, הקו בתהליך והמתכנן
assets/fonts/         IBM Plex Sans Hebrew ו־Gveret Levin (רישיון OFL)
assets/img/           לוגו, אייקונים וצילומי מסך בפורמט WebP (כולל צילומים ארוכים שגוללים בתוך המסגרות)
```

## עבודה חדשה

1. **צילום:** לצלם את האתר במחשב (1440 רוחב, כ־4,500 פיקסלים גובה) ובטלפון (390 רוחב, כ־4,200 גובה).
2. **שמירה:** לשמור ב־`assets/img/` בשמות `שם-tall-d.webp` (900 רוחב) ו־`שם-tall-m.webp` (300 רוחב).
3. **הוספה לעמוד:** להעתיק בלוק `<article class="case">` ב־`index.html` ולעדכן טקסט, תמונות וקישורים.
