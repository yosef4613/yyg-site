## איך מיושמים חמשת הכללים

### 1. מבחן המראה
המסך הראשון עונה על שלוש השאלות:
- **למי:** "לעסקים קטנים ולמוסדות".
- **מה מקבלים:** "אתר שנטען מהר ומביא פניות", ולפני שבונים רואים כמה עיצובים.
- **מה עושים עכשיו:** כפתור אחד, "לתכנן את האתר שלי". מתחתיו שורה שקטה עם הטלפון.

### 2. כלל המרקר (60-30-10)
- **60%:** פלדה כהה ברקע.
- **30%:** פלדה בהירה לטקסט, למסגרות ולכרטיסים.
- **10%:** זהב מוברש כמו בלוגו, **רק** על שלושה כפתורי פעולה: "לתכנן את האתר שלי", "לשלוח את התכנית במייל" ו"לשלוח מייל".

### 3. רקע, אמצע, חזית
- **רקע:** פלדה מוברשת, הילה רכה וטבעת חוגה מהלוגו.
- **אמצע:** חפיסת העיצובים יורדת לתוך החלק של העבודות, והטלפון יוצא מהמסגרת.
- **חזית:** הכפתור הזהוב, מרוץ המהירות וכרטיס התוצאה במתכנן מורמים עם צל.

### 4. תנועה עם תפקיד
לכל תנועה יש אחד משלושת התפקידים מהסרטון, ובכל מסך זז רק דבר אחד:

| איפה | מה זז | התפקיד |
|---|---|---|
| פתיחה | חפיסה תלת־ממדית של 5 כיווני העיצוב: נפרסת פעם אחת בטעינה, מתחלפת בלחיצה ונוטה לפי העכבר | להראות את המוצר מכמה זוויות |
| עבודות | המסכים במחשב ובטלפון גוללים את האתר האמיתי בזמן שגוללים את העמוד | להראות את המוצר |
| מרוץ המהירות | 8.5 שניות מול כ־2 שניות, עם כפתור "להריץ שוב" | להראות את התוצאה |
| איך עובדים | הקו מתמלא בגלילה, וכל מספר "נדלק" כשהקו מגיע אליו | להוביל את העין |
| מתכנן | המחיר מתגלגל לערך החדש, ומה שהשתנה מהבהב | להראות מה השתנה |

- **לא מחכים למילים:** אף טקסט לא מופיע באיחור. רק התמונות זזות.
- **מתג "תנועה":** בראש העמוד, נשמר בדפדפן. אם במערכת מוגדר "הפחתת תנועה", האתר נפתח כשהתנועה כבויה.
- **ברק על כפתור הזהב:** מופיע רק כשמרחפים עליו, כתגובה לפעולה.

### 5. דוגמה חינם
המתכנן הוא שאלון קצר עם הערכת מחיר:
- **התוצאה:** מסלול (דף נחיתה, אתר עם אזור ניהול, אתר ומועדון עדכונים, חנות אונליין), רשימת עמודים ויכולות.
- **המחיר:** קצת מתחת לאמצע השוק בארץ, ומה שכלול במסלול: כיווני עיצוב, סבבי תיקונים, זמן אספקה וליווי.
- **השליחה:** התכנית נשלחת במייל או מועתקת בלחיצה.

## מסלולים ומחירים

**איפה מעדכנים:** המחירים ומה שכלול בכל מסלול כתובים במקום אחד, בכרטיסי המסלולים ב־`index.html` (`data-price`, `data-en` והשורות `pkg-row`). המתכנן קורא אותם משם. `CONFIG.showPrice = false` מסתיר את הערכת המחיר במתכנן.

**התמחור:** קצת מתחת לאמצע השוק בארץ. כל המחירים לפני מע״מ.

**השוואה לשוק:**
