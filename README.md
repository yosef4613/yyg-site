## איך מיושמים חמשת הכללים

### 1. מבחן המראה
המסך הראשון עונה על שלוש השאלות:
- **למי:** "לעסקים קטנים ולמוסדות".
- **מה מקבלים:** "אתר שנטען מהר ומביא פניות", ולפני שבונים רואים כמה עיצובים.
- **מה עושים עכשיו:** כפתור אחד, "לתכנן את האתר שלי". מתחתיו שורה שקטה עם הטלפון.

### 2. כלל המרקר (60-30-10), בצבעי הלוגו
- **60%:** פלדה כהה ברקע.
- **30%:** פלדה בהירה לטקסט, למסגרות ולכרטיסים.
- **10%:** זהב מוברש, **רק** על כפתורי פעולה: "לתכנן את האתר שלי", "לשלוח את התכנית במייל", "לבחור במסלול" של המסלול המומלץ ו"לשלוח מייל".
- **טורקיז:** הזוהר מהלוגו משמש רק כאור, קווים ורקע. הוא אף פעם לא ממלא כפתור.

### 3. רקע, אמצע, חזית
- **רקע:** פלדה מוברשת, הילת טורקיז, טבעת חוגה וטבעת מסלול מהלוגו, ואור שעוקב אחרי העכבר.
- **אמצע:** חפיסת העיצובים יורדת לתוך החלק של העבודות, והטלפון יוצא מהמסגרת.
- **חזית:** הכפתור הזהוב, המרוץ, כרטיס התוצאה במתכנן וכרטיס המסלול שנבחר מורמים עם צל ואור.

### 4. תנועה עם תפקיד
לכל תנועה יש אחד משלושת התפקידים מהסרטון, ובכל מסך זז רק דבר אחד:

| מסך | מה זז | התפקיד |
|---|---|---|
| פתיחה | חפיסה תלת־ממדית של כיווני העיצוב: נפרסת פעם אחת, נוטה עם העכבר, וקו סריקה עובר על הקלף שעלה קדימה | להראות את המוצר |
| עבודות | המסכים במחשב ובטלפון גוללים את האתרים החיים בזמן הגלילה | להראות את המוצר |
| מרוץ | 8.5 שניות מול 2.9 שניות (נמדד ב־hakef.com), עם שעון שרץ על הפס | להראות את התוצאה |
| משרטוט לאתר | השרטוט "נבנה" לאתר החי בזמן הגלילה, ואפשר לגרור את הידית | להראות שינוי מצב |
| איך עובדים | קו אור מתמלא, ודופק טורקיז מדליק כל שלב | להוביל את העין |
| מתכנן | המחיר מתגלגל, עמודים חדשים קופצים למפה, והכרטיס מהבהב | להראות מה השתנה |
| מסלולים | מסגרת אור מסתובבת סביב המסלול המומלץ, רק כשרואים אותה | להוביל את העין |
| יצירת קשר | קו אור נמשך אל הכפתור | להוביל את העין |

- **תגובות לפעולה:** כרטיס מורם בריחוף, ברק על הלוגו ועל כפתור הזהב, וסימון ✓ על המסלול שנבחר.
- **לא מחכים למילים:** אף טקסט לא מופיע באיחור.
- **מתג "תנועה":** כיבוי מלא. אם במערכת מוגדר "הפחתת תנועה", האתר נפתח כשהתנועה כבויה.

### 5. דוגמה חינם
המתכנן הוא שאלון קצר עם הערכת מחיר:
- **התוצאה:** מסלול (דף נחיתה, אתר עם אזור ניהול, אתר ומועדון עדכונים, חנות אונליין), רשימת עמודים ויכולות.
- **המחיר:** קצת מתחת לאמצע השוק בארץ, ומה שכלול במסלול: כיווני עיצוב, סבבי תיקונים, זמן אספקה וליווי.
- **השליחה:** התכנית נשלחת במייל או מועתקת בלחיצה. הקישור "מה עוד כלול במסלול הזה" קופץ לכרטיס המתאים.

### בחירת מסלול
לחיצה על כרטיס מסלול, או על "לבחור במסלול הזה", מסמנת אותו וממשיכה ליצירת קשר. שם מוצג סיכום המסלול, עם אפשרות להוסיף אנגלית, וכפתור המייל נפתח עם כל הפרטים.

### בדיקה אוטומטית של הכללים
הבדיקה רצה במחשב (1440) ובטלפון (390). היא בודקת:

- **טורקיז:** לא ממלא אף כפתור.
- **שכבות:** רקע, אמצע וחזית, וכמה המסגרת חוצה את קצה החלק.
- **טקסט:** אין טקסט שמופיע באיחור.
- **תנועה:** מתג "תנועה" ו"הפחתת תנועה" עוצרים את כל התנועה.
